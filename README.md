# RuiEngine

A lightweight C++ game engine built for learning, experimentation, and extensibility flollowed Cherno.

> ⚠️ RuiEngine is under active development. APIs and systems may change frequently.

---

## ✨ Overview

**RuiEngine** is a custom C++ 2d game engine designed to explore the core architecture
of modern real-time engines, including rendering, ECS, asset management, and editor integration.

The project focuses on **clarity, modularity, and hands-on engine development**, serving
both as a learning platform and a foundation for future extensions.

---

## 🚀 Features

> Implemented and planned features are listed below and will be updated continuously.

### Core Systems
- [x] Application & window lifecycle management
- [x] Layer-based engine architecture
- [x] Event system (keyboard, mouse, window events)
- [x] UUID-based entity identification

### ECS (Entity Component System)
- [x] ECS architecture based on `entt`
- [x] Core components (Transform, Camera, SpriteRenderer, etc.)
- [x] Runtime entity creation and destruction
- [x] Scene serialization and deserialization (YAML)

### Rendering
- [x] 2D Renderer (batched sprite rendering)
- [x] Orthographic camera system
- [ ] 3D rendering pipeline
- [ ] PBR materials and lighting
- [ ] GPU-driven rendering optimizations

### Editor
- [x] ImGui-based editor framework
- [x] Scene hierarchy panel
- [x] Inspector panel for component editing
- [x] Asset browser
- [x] Editor gizmos (translate / rotate / scale)

### Scripting & Extensibility
- [x] Native C++ scripting system
- [ ] Runtime scripting (Lua / C# / Python)
